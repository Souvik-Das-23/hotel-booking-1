# Seaside Hotel — Luxury Resort & Booking Experience

A classic premium, animated, and transforming luxury hotel booking web application inspired by high-end hospitality designs.

![Seaside Hotel Preview](assets/images/hero-lounge.jpg)

## 🌟 Features

- **Classic Premium Aesthetics**: Rich ochre, warm cognac, champagne gold, and dark espresso color palette.
- **Transforming 3D Tilt Room Cards**: Dynamic perspective-shift on hover with image gallery preview, specs, and instant reservation trigger.
- **Multi-Step Interactive Booking Engine**:
  - Step 1: Stay details & dynamic night/room price calculator
  - Step 2: Bespoke luxury add-ons (Dom Pérignon, Chauffeur transfer, Couples Spa, Beachfront Dining)
  - Step 3: Guest information with real-time tax & promo code discounts (`SEASIDE20`, `RIVIERA25`)
  - Step 4: Instant booking voucher with confirmation code, QR pass, and print option
- **Dynamic Room Quick View Modal**: High-res multi-image switcher, floor specs, and included amenities.
- **Ambient Soundscape Engine**: Web Audio API generated calming ocean surf and soft warm piano chords.
- **Interactive Virtual Concierge (Pierre)**: Smart chat assistant for instant room, dining, and spa recommendations.
- **World-Class Amenities Showcase**: Interactive tabs for 3-Michelin Star Dining, Thermal Spa, Infinity Pools, and Private Yacht Charters.
- **Interactive Testimonials**: Animated luxury guest reviews carousel.
- **Seasonal Privilege Countdown Timer**: Real-time ticker with promo code integration.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

## 🛠️ Built With

- **HTML5 & Vanilla CSS3** (Custom design tokens, glassmorphism, responsive CSS grid/flexbox)
- **Modern JavaScript (ES Modules)**
- **Google Fonts**: *Playfair Display*, *Cinzel*, *Cormorant Garamond*, *Plus Jakarta Sans*
- **Lucide Icons**
- **Vite** (Dev server & asset pipeline)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running Locally

1. Clone the repository:
```bash
git clone https://github.com/Souvik-Das-23/hotel-booking-1.git
cd hotel-booking-1
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
